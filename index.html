Install the firmware

You need a Flipper Zero with a microSD card inserted.

With the Zaku's Lab tool

  1. Connect your Flipper over USB and open the tool.
  2. Open the ⇄ Firmware switcher tab.
  3. Pick Zaku's Lab and press Switch firmware.

With the free official qFlipper

  1. Download the firmware file above (.tgz).
  2. In qFlipper, click Install from file and choose it.
  3. Wait for your Flipper to reboot. Your SD card files are kept.

    FAQ

    Is the firmware really free?

    Yes. The firmware is free to download and use, now and for every update. It's open source under GPL-3.0.

    Why is the tool paid?

    You're paying for a polished, ready-to-run Windows build of the Zaku's Lab tool plus its updates and support. The tool is open source (GPL-3.0, based on qFlipper by Flipper Devices), and the full source code is included with your purchase.

    Do I need the tool to install the firmware?

    No. The free official qFlipper app can install it with Install from file. The tool just makes it one click and adds the firmware switcher and dev board flasher.

    Can I go back to the official firmware?

    Any time. Use qFlipper's (or the tool's) Update button to reinstall official firmware. Your SD card files stay put.

    Which devices are supported?

    Flipper Zero (hardware f7) with a microSD card. The tool runs on Windows 10 and 11 (64-bit).

    How do I check my download?

    Compare the file's SHA-256 with the checksum shown under the download button. On Windows: certutil -hashfile file.tgz SHA256.
